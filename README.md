# To-Do List Web Application

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. The application allows users to create and manage daily tasks with due dates and times.

## Features

- Add new tasks
- Set a date for each task
- Set a time for each task
- Mark tasks as completed using a checkbox
- Delete tasks
- Filter tasks by:
  - All
  - Pending
  - Completed
- Tasks are saved using browser Local Storage
- Tasks remain available after refreshing the page
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
